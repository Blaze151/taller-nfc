Conectar con el repositorio

Se conecta directo a tu repositorio de GitHub usando un token personal. Los cambios que hagas aquí se guardan como commits en data/vehicles.json.

El token queda guardado en este dispositivo (no se comparte ni se sube a ningún lado) hasta que presiones "Cerrar sesión". Úsalo solo en tu celular o computadora del taller, no en equipos compartidos. Crea el token en GitHub → Settings → Developer settings → Fine-grained tokens, limitado únicamente a este repositorio.
